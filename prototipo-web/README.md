# Interfaz web de apoyo

Abre `index.html` en el navegador desde la carpeta descargada. El documento LEEME.md describe el recorrido.

Esta interfaz utiliza HTML, CSS y JavaScript, con almacenamiento local. Es independiente del modelo Python situado en `sigha/`: no llama a ese código ni demuestra por sí sola que exista una conexión con Python o con una base de datos.

El repositorio incluye ambas piezas para diferenciar el modelo de POO y la propuesta de interfaz. La conexión entre ellas queda pendiente.
