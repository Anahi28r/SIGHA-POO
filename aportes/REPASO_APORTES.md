# Repaso: de Python básico al aporte de POO

Relaciona cada respuesta con una línea del ejemplo que vas a explicar.

| Tema | Pregunta de repaso | Respuesta breve |
| --- | --- | --- |
| Tipos básicos | ¿Qué guardo en una cadena, un entero y un booleano? | Texto, números enteros y valores True/False, respectivamente. |
| Entrada | ¿Qué devuelve input()? | Una cadena; una conversión con int puede fallar si el texto no representa un entero. |
| Listas | ¿Qué representa una lista de días? | Una secuencia ordenada de valores. |
| Matriz | ¿Qué representan filas y columnas en el ejemplo? | Periodos y días. |
| Bucles | ¿Para qué sirve for? | Para recorrer elementos o una secuencia de valores. |
| Funciones | ¿Qué ocurre si una función termina sin return explícito? | Devuelve None. |
| Clase y objeto | ¿Docente y docente1 son lo mismo? | No: Docente es la clase; docente1 puede referirse a una instancia. |
| Constructor | ¿Qué hace __init__? | Inicializa los datos de una instancia. |
| self | ¿Qué representa? | La instancia que recibe la llamada al método. |
| Atributos | ¿Nombre de un docente y estado general son equivalentes? | El nombre es individual; un atributo de clase se comparte mientras no se oculte con uno de instancia. |
| Métodos | ¿Qué reciben instancia, clase y estático? | self, cls y ninguno automáticamente, respectivamente. |
| Encapsulamiento | ¿Basta con poner __ a un atributo? | No; también hacen falta una interfaz clara y operaciones que controlen los cambios. |
| Herencia | ¿Cuál es la relación correcta en SIGHA? | Docente y Estudiante son tipos de Persona. |
| super() | ¿Para qué se usa en los constructores? | Para reutilizar la inicialización de la base con los argumentos adecuados. |
| Sobrescritura | ¿Qué hace una hija al definir su propio método? | Proporciona una versión propia; no ejecuta automáticamente la de la base. |
| pass | ¿Imprime algo o crea abstracción por sí mismo? | No hace ninguna de esas cosas. Es una instrucción que no realiza una acción. |
| Abstracción | ¿Qué aportan ABC y abstractmethod? | Una base que puede declarar operaciones requeridas para las clases concretas. |
| Polimorfismo | ¿Dónde se ve en las consultas? | En la misma llamada consultar() con distintas implementaciones. |
| Composición | ¿Dónde se ve en ServicioConsulta? | El servicio tiene un objeto consulta y lo utiliza. |
| Errores | ¿None, SyntaxError y TypeError son lo mismo? | No: None es un valor; SyntaxError indica sintaxis inválida y TypeError una operación o uso incompatible con los tipos o la llamada. |

## Preparación individual

2. Señala la práctica de la que surge.
3. Localiza el archivo y el método que la aplican.
4. Ejecuta un ejemplo y describe su resultado.
5. Diferencia lo implementado de lo pendiente.
